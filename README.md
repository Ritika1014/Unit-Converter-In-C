# Unit Converter in C

A menu-driven console application that converts between common length, weight, and temperature units. Written in C and designed for a beginner-friendly terminal experience.

## Features

- **Length:** meters to kilometers, centimeters, and inches; kilometers, centimeters, and inches to meters
- **Weight:** kilograms to grams and pounds; grams and pounds to kilograms
- **Temperature:** Celsius, Fahrenheit, and Kelvin conversions (each selection displays the other two scales)

## Requirements

A C compiler such as GCC.

## Build

```sh
gcc unitconveter_miniprojectritika.c -o unit_converter
```

## Run

On Linux or macOS:

```sh
./unit_converter
```

On Windows (PowerShell):

```powershell
.\unit_converter.exe
```

Choose a converter from the main menu, then select a conversion and enter the value when prompted. Select **4** from the main menu to exit.
